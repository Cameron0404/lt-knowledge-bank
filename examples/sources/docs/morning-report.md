# The morning report (EXAMPLE source, invented)

This file is an invented example for the knowledge bank demo. It describes no real system.

## What it shows

The morning report lists every scheduled job that did not run since the last report.
A job that failed shows its exit code and the last ten lines of its log.

## Where it goes

The report is written to reports/morning.md at 07:00 and is never emailed.
